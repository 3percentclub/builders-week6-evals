# Week 6 slides (Slidev copy)

A portable copy of the Week 6 Builders deck for guest instructors.
The live deck at https://builders-slides.vercel.app/week-6 is the real one. **Don't edit `slides.md` by hand**: it gets regenerated from the live deck.

## Present it

```bash
cd slides
npm install
npm run dev       # opens the deck in your browser
```

- Press **P** (or open `/presenter`) for presenter mode. Your talking points are in the speaker notes there; the class never sees them.
- `npm run export` makes a PDF (needs `playwright-chromium`, Slidev will prompt to install it).

## Suggest a change

Open an issue or message Maria. Changes go into the live deck first, then this copy is regenerated.

Answer keys aren't in this deck. If you're teaching, ask Maria for the instructor notes.
